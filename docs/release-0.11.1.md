# Bildblick 0.11.1

This bug-fix release repairs the Flatpak startup failure reported on Linux Mint 22.3 and other distributions. The package now installs `design-system/tokens.json` at the path expected by the GTK theme loader.

Download `Bildblick-0.11.1.flatpak` from this release and open it with the Software app, or run:

```bash
flatpak install --user ./Bildblick-0.11.1.flatpak
```

The release also includes the updated Linux source archive and its SHA-256 checksum.
