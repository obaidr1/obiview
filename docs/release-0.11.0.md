# Bildblick 0.11.0

Bildblick is now available as a Flatpak for x86-64 Linux desktops. The package carries its image-processing dependency and uses the GNOME runtime, so users do not need to install Python, GTK or Pillow through their distribution's package manager.

Install Flatpak and enable Flathub, then download `Bildblick-0.11.0.flatpak` from this release and open it with the Software app, or run:

```bash
flatpak install --user ./Bildblick-0.11.0.flatpak
```

The existing source archive remains available for users who prefer their distribution's system libraries.
