# Bildblick 0.11.2

This release adds an x86-64 AppImage alongside the Flatpak and the Linux system archive. The AppImage includes an Ubuntu 22.04 based GTK/Python runtime and can be launched after downloading it. A system FUSE 2 compatibility library may be needed on some distributions.

Download `Bildblick-0.11.2-x86_64.AppImage`, make it executable if your file manager has not already done so, and launch it:

```bash
chmod +x Bildblick-0.11.2-x86_64.AppImage
./Bildblick-0.11.2-x86_64.AppImage
```

The Flatpak remains available as `Bildblick-0.11.2.flatpak` for users who prefer software-center installation and sandboxed file access.
