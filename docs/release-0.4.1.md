# Bildblick 0.4.1

Das Hauptfenster folgt jetzt der Struktur eines kompakten Bildbetrachters und behält
das neue helle, monochrome Design.

- Startgröße: 720 × 640 Pixel.
- Dauerhaft sichtbare Menüleiste, eine schmale Symbolleiste und eine Statuszeile.
- Die Bildfläche nutzt die gesamte verfügbare Breite; keine seitlichen Regler oder schwebenden Werkzeuge.
- Öffnen, Speichern, Ausschnitt, Historie, Informationen, Zoom und Navigation direkt in der Werkzeugleiste.
- Bildanpassungen mit eigener Vorschau in einem separaten Dialog.
- Vorschaubilder in einem eigenen Fenster.
- Größenänderung über Symbol, Menü oder Strg+R; Export und weitere Werkzeuge bleiben eigene Dialoge.

Die GUI-Prüfung kontrolliert die genaue Startgröße, sichtbare Menüs, die Breite der
Bildfläche sowie Öffnen, Abbrechen und Anwenden der ausgelagerten Werkzeuge.
Die 62 Funktionstests bleiben Bestandteil der Veröffentlichung.

Zur Aktualisierung das Archiv entpacken und `./install.sh` ausführen. Eine laufende
ältere Version schließen und Bildblick erneut öffnen. Exportprofile bleiben erhalten.
