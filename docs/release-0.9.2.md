# Bildblick 0.9.2

Kompakte Abfrage für ungespeicherte Änderungen mit vollständig sichtbarem Erklärungstext und den Optionen Speichern, Verwerfen und Abbrechen. Speichern führt die angeforderte Aktion erst nach erfolgreichem Speichern in voller Auflösung aus. Abgebrochene oder fehlgeschlagene Exporte lassen das Arbeitsbild geöffnet.
